版本 v1.0 ｜ 2026-10-13 ｜ 状态：待确认

## 1. 整体框架

### 1.1 页面骨架

```
┌────────────────────────────────────────────────────────┐
│  计算器      [ 计算 ][ 换算 ][ 日期 ][ 历史 ]      设置  │  顶栏 56px
├────────────────────────────────────────────────────────┤
│                                                        │
│                    主工作区                             │
│              最大宽 880px，水平居中                      │
│                                                        │
└────────────────────────────────────────────────────────┘
```

- 单个页面，无路由、无跳转。切换视图只是把对应区块显示/隐藏
- 顶栏固定：左侧标题、中间四个视图入口（当前项高亮）、右侧设置入口
- 背景浅灰，内容区用白底卡片，圆角 12px，边框 1px
- 最小支持窗口宽度 1024px，不做移动端适配

### 1.2 视觉基调

| 项目 | 取值 |
| --- | --- |
| 背景 | `#F7F7F5` |
| 卡片 | `#FFFFFF`，边框 `#E5E4E0` |
| 主文字 | `#2C2C2A` |
| 次要文字 | `#6B6B66` |
| 强调色 | `#1D9E75`（选中态、等号键） |
| 危险色 | `#E24B4A`（删除、清空） |
| 正文字号 | 14px |
| 显示屏数字 | 40px，等宽数字（tabular-nums）|

### 1.3 视图切换规则

- 记住上次停留的视图，下次打开直接回到该视图
- 切走再切回来，各视图已输入的内容不丢（保留在内存中，不写历史）
- 快捷键 `1 / 2 / 3 / 4` 可切换视图（可选，待确认）

## 2. 计算视图

### 2.1 布局

```
┌──────────────────────────────────────┐
│                       12 × 8 +       │  ← 副显示 14px 灰
│                            101       │  ← 主显示 40px
├──────────────────────────────────────┤
│    C    │   ⌫    │   ％   │   ÷      │
│    7    │    8   │    9   │   ×      │
│    4    │    5   │    6   │   −      │
│    1    │    2   │    3   │   +      │
│    ±    │    0   │    .   │   =      │
└──────────────────────────────────────┘
```

键盘区 4 列 × 5 行，按键高度 56px，等号键用强调色填充。

### 2.2 显示区规则

- 主显示：当前输入的数字或最近一次结果，右对齐，整数部分加千分位分隔（可在设置里关闭）
- 副显示：正在构建的完整表达式，如 `12 × 8 +`
- 数字有效位超过 14 位时自动改用科学计数法显示（如 `1.2345e+15`）
- 计算结果最长保留 12 位有效数字，并去掉尾部多余的零

### 2.3 运算规则

- 按标准优先级运算：`× ÷` 高于 `+ −`，不是顺序计算
- 连续按运算符时，替换掉上一个运算符（不做连算）
- 计算结果后继续按数字，开始新一轮输入；按运算符则在结果上继续算
- 浮点误差修正：先按 12 位有效数字裁剪再显示，避免出现 `0.30000000000000004`

### 2.4 键盘映射

| 物理按键 | 对应操作 |
| --- | --- |
| `0`–`9`、`.` | 数字与小数点 |
| `+` `-` `*` `/` | 加、减、乘、除 |
| `Enter` 或 `=` | 等于 |
| `Backspace` | 退格删除一位 |
| `Esc` 或 `Delete` | 清空全部输入 |
| `%` | 百分号 |
| 小键盘数字区 | 同样有效 |

### 2.5 错误与边界

| 情况 | 表现 |
| --- | --- |
| 除以零 | 主显示"无法除以零"，下次按数字自动重置 |
| 连按小数点 | 第二个小数点被忽略 |
| 数字首位是 0 | 自动替换，如 `0` 后按 `5` 直接得 `5` |
| 极长数字 | 超出 14 位转科学计数法，计算仍按完整精度 |

## 3. 换算视图

### 3.1 布局

```
[ 长度 ][ 重量 ][ 温度 ][ 面积 ][ 体积 ]        ← 类别标签

┌──────────────────────┐    ┌──────────────────────┐
│  [ 米          ▾ ]   │ ⇅  │  [ 英尺        ▾ ]   │
│  1                   │    │  3.28084             │
└──────────────────────┘    └──────────────────────┘

▸ 该类别的全部单位对照（可折叠）
```

### 3.2 单位清单

| 类别 | 包含单位 |
| --- | --- |
| 长度 | 毫米、厘米、米、千米、英寸、英尺、码、英里 |
| 重量 | 毫克、克、千克、吨、盎司、磅 |
| 温度 | 摄氏度、华氏度、开尔文 |
| 面积 | 平方厘米、平方米、平方千米、公顷、平方英尺、英亩、平方英里 |
| 体积 | 毫升、升、立方厘米、立方米、美制加仑、英制加仑、液盎司 |

除温度外，各类别以公制基准单位（米、千克、平方米、立方米）换算，温度走独立公式。

### 3.3 交互流程

1. 选类别 → 载入该类别的默认单位对（长度：米 ↔ 英尺；重量：千克 ↔ 磅；温度：摄氏度 ↔ 华氏度；面积：平方米 ↔ 平方英尺；体积：升 ↔ 美制加仑）
2. 在任意一侧输入数字 → 另一侧实时更新
3. 点中间 ⇅ → 交换两侧单位，保留左侧数字，按新单位重算右侧
4. 结果保留 6 位小数并去掉尾零；过大或过小改用科学计数法
5. 折叠区展示该类别下"当前数值换算成所有单位"的对照列表

### 3.4 边界

- 输入框留空 → 另一侧显示空白，不报错
- 输入非法字符 → 输入框标红，不计算
- 温度支持负值（零下）

## 4. 日期视图

三个功能纵向排列成三张卡片，每张独立可用，互不影响。

### 4.1 卡片 A · 日期相差与倒计时

- 输入：起始日期、结束日期（默认都是今天）
- 输出：
  - 相差 `N` 天（含首日则 `N+1` 天）
  - 折合 `X` 周 `Y` 天
  - 约 `M` 个月
- 结束日期早于起始日期时，结果显示为负数并附一句提示

### 4.2 卡片 B · 日期加减推演

- 输入：起始日期、方向（之后 / 之前）、数值、单位（天 / 周 / 月 / 年）
- 输出：结果日期 `YYYY-MM-DD`，并显示当天是星期几

### 4.3 卡片 C · 年龄与纪念日

- 输入：出生日期或纪念日
- 输出：
  - 精确年龄：`N 年 M 月 D 天`
  - 已经过去的总天数
  - 距离下一个周年还有多少天，及下次日期与星期几

### 4.4 边界

| 情况 | 处理 |
| --- | --- |
| 加减月份遇到月末 | 按目标月最后一天处理，如 1 月 31 日 + 1 个月 = 2 月 28/29 日 |
| 2 月 29 日出生，遇非闰年 | 周年按 3 月 1 日计算 |
| 日期未填全 | 结果区显示"—"，不报错 |
| 手输非法日期 | 输入框标红，暂停计算 |

## 5. 历史视图

### 5.1 布局

```
┌──────────────────────────────────────────────────────────┐
│ [ 搜索记录............ ]  [全部|计算|换算|日期]  [清空全部] │
├──────────────────────────────────────────────────────────┤
│  12 × 8 + 5                                    101   ✕   │
│  计算 · 今天 10:24                                        │
├──────────────────────────────────────────────────────────┤
│  1 米 → 英尺                              3.28084   ✕   │
│  换算 · 今天 10:22                                        │
└──────────────────────────────────────────────────────────┘
```

### 5.2 交互

- 按时间倒序排列，最新的在最上方
- 搜索框匹配"表达式"与"结果"两段文本，不区分大小写
- 类型筛选：全部 / 计算 / 换算 / 日期
- 删除按钮默认淡显，鼠标移到该行时变明显
- 点记录行左侧主体区域 → 把这条的参数重新填回对应视图，便于改一个数重算
- 「清空全部」弹出二次确认："确定清空全部 N 条记录？此操作无法撤销。"

### 5.3 空状态

无记录时居中显示一句话："还没有记录。算点什么，这里会自动留下痕迹。"

## 6. 数据存储设计

### 6.1 选型

用浏览器自带的 **localStorage**，不用 IndexedDB。

理由：500 条记录总量不到 200KB，远低于 localStorage 的 5MB 上限；同步读写、实现简单、出问题能直接在开发者工具里看到内容。

### 6.2 存储键与结构

两个键，互相独立，互不影响：

```
calcapp.settings.v1
calcapp.history.v1
```

**settings**

```json
{
  "version": 1,
  "lastView": "calc",
  "historyLimit": 500,
  "thousandSeparator": true,
  "lastConvertCategory": "length",
  "lastUnits": { "length": ["m", "ft"], "weight": ["kg", "lb"] },
  "lastDates": { "start": "2026-10-13", "end": "2026-11-01" }
}
```

**history**（数组，索引 0 最新）

```json
[
  {
    "id": "1728800000000-1",
    "type": "calc",
    "title": "12 × 8 + 5",
    "result": "101",
    "detail": { "expression": "12*8+5" },
    "createdAt": 1728800000000
  },
  {
    "id": "1728800001000-2",
    "type": "convert",
    "title": "1 米 → 英尺",
    "result": "3.28084",
    "detail": { "category": "length", "from": "m", "to": "ft", "value": 1 },
    "createdAt": 1728800001000
  },
  {
    "id": "1728800002000-3",
    "type": "date",
    "title": "2026-10-13 → 2026-11-01",
    "result": "19 天",
    "detail": { "mode": "diff", "start": "2026-10-13", "end": "2026-11-01" },
    "createdAt": 1728800002000
  }
]
```

`detail` 字段是"重新填入"的依据，三种类型的结构不同但都由 type 区分。

### 6.3 写入时机

| 来源 | 时机 |
| --- | --- |
| 计算 | 按下等号且计算成功时写一条 |
| 换算 | 输入停止 800ms 后写一条；同一单位对 + 同一数值不重复写 |
| 日期 | 输入齐全后 800ms 防抖写一条 |

每次写入前先读现有数组，插入到头部，再整体写回。

### 6.4 容量与淘汰

- 默认上限 500 条，超出后从尾部（最旧）裁剪
- 上限值放在设置里，后续可调

### 6.5 风险与备份

- 浏览器里"清除浏览数据"会把记录一起清掉，localStorage 和 IndexedDB 都躲不过
- 无痕模式、换浏览器、换电脑都不共享数据
- 因此**建议**在第一版加"导出 JSON / 导入 JSON"两个按钮，作为手动备份手段（待确认）
