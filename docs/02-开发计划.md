**关键实现要点（可直接照此编码）**

求值算法：因为键盘只产生「数字、运算符」交替序列，不需要完整表达式解析器，两趟扫描即可天然实现标准优先级。

```js
function evaluate(tokens) {
  const t = tokens.slice();
  for (let i = 1; i < t.length; i += 2) {
    const op = t[i].v;
    if (op === '*' || op === '/') {
      if (op === '/' && t[i + 1].v === 0) throw new Error('DIV_ZERO');
      const v = op === '*' ? t[i - 1].v * t[i + 1].v : t[i - 1].v / t[i + 1].v;
      t.splice(i - 1, 3, { type: 'num', v });
      i -= 2;
    }
  }
  let acc = t[0].v;
  for (let i = 1; i < t.length; i += 2) {
    acc = t[i].v === '+' ? acc + t[i + 1].v : acc - t[i + 1].v;
  }
  return acc;
}
```

数字格式化：这一步同时解决浮点误差与显示问题。

```js
function formatNumber(n) {
  if (!isFinite(n)) return '无法计算';
  if (n === 0) return '0';
  const abs = Math.abs(n);
  if (abs >= 1e15 || abs < 1e-9) return trimExp(n.toExponential(8));
  let s = n.toPrecision(12);
  if (s.includes('e')) return trimExp(s);
  if (s.includes('.')) s = s.replace(/0+$/, '').replace(/\.$/, '');
  return s;
}
```

- `0.1 + 0.2` → `0.300000000000` → 去尾零 → `0.3` ✅
- `12 * 8 + 5` → `101.000000000` → `101` ✅

状态机规则表：

| 当前状态 | 按数字 | 按运算符 | 按等号 | 按退格 |
| --- | --- | --- | --- | --- |
| 输入数字中 | 追加 | 收进 token，转「刚按运算符」 | 求值 | 删一位，删空显示 `0` |
| 刚按运算符 | 开始新数字 | 替换上一个运算符 | 用待输入数字时忽略 | 删掉该运算符 |
| 刚出结果 | 开启新计算 | 在结果上继续算 | 重算一次不写历史 | 无操作 |

**关键实现要点**

**所有日期必须用「年月日」构造本地时间，禁止用 `new Date('2026-10-13')`**，后者会被当作 UTC 解析，在东八区会整体差一天。

```js
function parseDate(s) {                       // 'YYYY-MM-DD' -> Date
  const [y, m, d] = s.split('-').map(Number);
  return new Date(y, m - 1, d);
}
function formatDate(dt) {
  const p = n => String(n).padStart(2, '0');
  return `${dt.getFullYear()}-${p(dt.getMonth() + 1)}-${p(dt.getDate())}`;
}
function daysBetween(a, b) {                  // 按自然日计，返回可正可负
  const A = new Date(a.getFullYear(), a.getMonth(), a.getDate());
  const B = new Date(b.getFullYear(), b.getMonth(), b.getDate());
  return Math.round((B - A) / 86400000);
}
function addMonths(dt, n) {                   // 月末溢出取目标月最后一天
  const target = new Date(dt.getFullYear(), dt.getMonth() + n, 1);
  const lastDay = new Date(target.getFullYear(), target.getMonth() + 1, 0).getDate();
  return new Date(target.getFullYear(), target.getMonth(), Math.min(dt.getDate(), lastDay));
}
```

校验：`2026-01-31` +1 月 → `2026-02-28` ✅；`2024-01-31` +1 月 → `2024-02-29` ✅；`2026-10-13` +30 天 → `2026-11-12 周四` ✅（已用系统命令核对）

精确年龄（同样要处理跨月借位）：

```js
function ageFrom(birth, ref) {
  let y = ref.getFullYear() - birth.getFullYear();
  let m = ref.getMonth() - birth.getMonth();
  let d = ref.getDate() - birth.getDate();
  if (d < 0) { m--; d += new Date(ref.getFullYear(), ref.getMonth(), 0).getDate(); }
  if (m < 0) { y--; m += 12; }
  return { y, m, d };
}
```

下次周年：若当年周年日已过则取次年；`2 月 29 日` 出生在非闰年按 `3 月 1 日` 计算，用一个 `anniversaryDate(birth, year)` 统一封装。

| --- | --- |
| `Store.loadSettings()` | 读 settings，失败回落默认值 |

| `Store.deleteRecord(id)` | 按 id 删除 |
| `Store.clearHistory()` | 清空记录 |
| `Store.available` | 存储是否可用，供提示条使用 |

### 3.2 `file://` 下的注意事项

| 事项 | 说明 |
| --- | --- |
| 存储命名空间 | Chrome 下所有 `file://` 页面共用一个存储源，因此键名必须带 `calcapp.` 前缀，避免与其他本地页面冲突 |
| 下载备份 | `Blob` 下载在 `file://` 下可正常工作；若某浏览器拦截，改为生成 `data:` 链接兜底 |
| 浏览器差异 | 火狐、Chrome、Edge 正常；Safari 对 `file://` 存储限制较严，不作为目标浏览器 |
