# 计算器

一个不联网、不登录、数据只存在你自己浏览器里的生活工具型计算器。

没有框架、没有构建步骤、没有依赖、没有网络请求。下载下来双击 `index.html` 就能用，关掉浏览器再打开，记录和设置都还在。

## 功能

**计算** — 标准优先级四则运算（`×` `÷` 高于 `+` `−`），百分号用于折扣与涨跌，正负号切换。
支持物理键盘输入；结果按 12 位有效数字裁剪，`0.1 + 0.2` 得到 `0.3` 而不是 `0.30000000000000004`；除以零有明确提示并可继续操作。

**换算** — 长度、重量、温度、面积、体积五个类别，任意一侧输入另一侧实时更新，一键互换单位，可展开该类别全部单位的对照值。会记住你上次用的类别和单位对。

**日期** — 日期相差与倒计时（天数 / 周数 / 约几个月 / 含首日天数）、日期加减推演（天 / 周 / 月 / 年，带星期几）、年龄与纪念日（精确年月日、已过总天数、下次周年倒计时）。月末和闰年边界都做了处理：`2026-01-31` 加一个月得到 `2026-02-28`，2 月 29 日出生者在非闰年的周年按 3 月 1 日算。

**历史** — 上面三块的操作全部自动留痕，无需手动保存。支持关键词搜索、按类型筛选、单条删除、清空全部（二次确认），点任意一条可以把它回填到来源视图，改个数就能重算。

**设置** — 千分位分隔开关、历史记录条数上限、当前数据量显示，以及 JSON 格式的备份导出与导入。

## 快速开始

```bash
git clone https://github.com/tayunchuan/calculator-app.git
cd calculator-app
```

然后双击 `index.html`，浏览器就打开了。不需要任何安装步骤。

> ### ⚠️ 从 ZIP 下载的话，务必先完整解压
>
> 在 GitHub 上点 **Code → Download ZIP** 拿到的是压缩包。如果你**直接在压缩包里双击 `index.html`**，
> 会看到一个没有任何样式的页面——按钮挤成一行小方块，点了也没反应。
>
> 这不是程序坏了。Windows 在压缩包内打开文件时，只会把你**双击的那一个文件**临时解压出来，
> `styles.css` 和 `app.js` 不会被一起解出，于是样式和逻辑全部丢失。
>
> **正确做法**：右键压缩包 → 「全部解压缩」→ 进入解压出的文件夹 → 再双击 `index.html`。
>
> 怎么判断自己打开对了？**看地址栏**：路径里不该出现 `AppData\Local\Temp`，也不该带 `.zip`。
>
> 另外，临时目录里跑的版本**数据存不住**——Windows 会清理 Temp，而浏览器的存储是绑在路径上的，
> 换个位置打开记录就"不见了"。所以务必解压后再用。

想在手机上或微信里发给别人，可以打包成可分享的形态：

```bash
npm run package
```

会在 `dist/` 下生成两个产物：一个是解压即用的 `zip` 压缩包，另一个是把 CSS 和 JS 全部内联的自包含单文件 HTML。

> 需要 Python 3（只用标准库，无需额外安装包）。

## 开发

环境要求：Node.js >= 22.22.2（**仅运行测试需要**，应用本身不需要 Node）。

```bash
npm install     # 安装测试依赖 jsdom
npm test        # 运行全部自动化测试
```

测试分两层，共 **147 条**：

1. **纯逻辑沙箱** — 用 `vm` 在无 `document` 的环境里加载 `app.js`，只测计算引擎与存储层。
2. **真实 DOM 沙箱** — 用 `jsdom` 加载 `index.html` 并执行 `app.js`，模拟点击验证完整交互流程。

如果想只跑某一步：

```bash
node tests/run-tests.js 3     # 只跑步骤 3（换算视图）
```

`jsdom` 装在非默认位置时，可以用环境变量指定：

```bash
LOCALCALC_NODE_MODULES=/path/to/node_modules node tests/run-tests.js
```

## 数据与隐私

这是这个项目最核心的设计取向：**你的数据不出这台机器**。

- 所有记录存在浏览器的 `localStorage`，两个键：`calcapp.settings.v1` 与 `calcapp.history.v1`
- 全程零网络请求，断网也能正常工作（PRD 里 A4 就是这条的验收项）
- 导出备份是本地生成 `.json` 文件并下载，同样不上传任何服务器

由此带来几个必须知道的限制：

- **不要用无痕 / 隐私模式打开**，那种模式关掉窗口数据就没了
- 浏览器「清除浏览数据」会清掉记录，重要数据请定期用「设置 → 导出备份」留存
- 换电脑、换浏览器数据不会跟着走，想迁移就用导出 → 在新环境导入

## 已知限制

- **只针对桌面宽屏设计**，最小支持 1024px 窗口宽度，手机端未做适配。手机上能打开，但布局会挤、需要横向滚动。
- **不做科学计算**（三角函数、对数、幂与开方、括号表达式）和**程序员模式**（进制互转、位运算）。
- **不做汇率换算** — 不联网就无法自动更新汇率，做出来只会误导人。
- 不支持多设备同步、登录账号、深色模式。

完整的「暂不实现」清单见 `PRD.md` 第 9 节。
